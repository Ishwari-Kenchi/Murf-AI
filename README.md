
# 🎙️ AI Voice Career Coach

An AI-powered platform that helps users improve their communication skills, prepare for interviews, and enhance their resumes using voice-based interaction and intelligent analysis.

---

## 🚀 Features

### 🎤 Voice Assistant
- Real-time voice interaction
- Speech-to-text input
- AI-generated responses
- Text + voice output (like Alexa)

### 💼 Interview Simulation
- Mock interview conversations
- Follow-up questions based on user answers
- Helps improve confidence and communication

### 📄 Resume Analyzer
- Upload or paste resume
- AI-generated feedback
- Resume score (0–10)
- Missing skills detection
- Weak section identification
- ATS optimization tips
- Example improvements (before → after)

---

## 🧠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** FastAPI (Python)  
- **AI Models:** Groq (LLM), OpenAI Whisper (STT)  
- **Text-to-Speech:** Murf AI  
- **Deployment:** Vercel  

---

## ⚙️ How It Works

1. User speaks through microphone  
2. Speech is converted to text (STT)  
3. AI processes the input and generates a response  
4. Response is converted to voice (TTS)  
5. Output is displayed as text and audio
